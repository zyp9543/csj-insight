# 公司动态（gsdt）

用于产业链周报的“企业动态”栏目。客户池以用户提供的 Excel 清单为唯一边界；若未提供清单，先请求清单，不按模型记忆或地域自行增补公司。

## 数据与时间口径

- 优先使用财汇 MCP 的“新闻舆情”能力，调用前先读取当前可见工具的描述和参数；结构化条件明确时使用 `search_news`。
- 默认冻结当前日期，时间窗口为最近一周（含报告日及此前连续7个自然日）；在输出中注明实际日期范围。
- 必须传入 `importance=["重要"]`，并传入附件客户池中的公司名称或证券代码。若结果为空，不得降低为“一般”后混入结果；应说明本周未发现符合条件的“重要”记录，除非用户明确要求扩展口径。
- 对有 `news_id` 的入选记录，再调用 `get_news_content` 获取正文；正文缺失或没有可核验 HTTP(S) 原文链接的记录不得入选。

## 选题规则

读取用户提供的公告/行业周报筛选建议 Markdown，并以其规则为准。优先保留能够说明经营、产业或风险变化的内容：

1. 业绩预告、业绩快报、定期报告及利润/现金流/毛利率显著变化；
2. 重大合同、中标、订单、客户或供应商变化；
3. 重大项目投资、扩产、投产、产能爬坡；
4. 新产品、新技术、认证、量产、临床或客户验证进展；
5. 收购、并购、重组、增资、出售资产等产业资本事项；
6. 重大诉讼、处罚、立案、破产重整、债务逾期、减值、存货跌价等经营风险。

默认过滤：普通担保进展、事务性董事会/股东大会公告、分红实施、回购、一般增减持、企业注销、限售股上市、股权激励归属、股票异动，以及只有股价涨跌而缺少经营事实的报道。若担保、股权或治理事项实际揭示了重大项目融资、债务风险或公司治理缺陷，可按其真实产业/风险含义重新提炼。

同一事实只保留一条；同一企业原则上不超过2条。优先公司公告、监管机构、交易所、法院或权威财经媒体；财汇 AI 摘要仅在有可核验原文链接且事实能够交叉确认时使用。

## 数量与写作

- 最终企业数量不超过8家，总动态不超过10条；优先覆盖近期性、重要性和产业/授信信息增量最高的企业。
- 每条固定输出：企业/事件标题、正文、出处、原文链接。
- 正文必须100—200字，直接讲清“发生了什么、涉及哪些关键数字或主体、对经营/产业/风险意味着什么”。不得写采集过程、模型判断或未经来源支持的推测。
- 正文采用“事实—影响/需关注点”结构，不把公告标题简单改写成摘要，不使用宣传性表述。
- 原文链接必须是内容发布者或上市公司/监管机构的最终 HTTP(S) 链接；不得展示财汇聚合链接、内部短链或无法打开的空链接。

## 输出前检查

逐条核对：企业在附件客户池内；发布日期在窗口内；财汇标签为“重要”；选题符合 MD 规则；正文100—200字；出处与原文链接齐全；企业数≤8、条数≤10；重复事实已删除。

若财汇工具调用失败、正文接口失败或原文链接不可核验，应明确标注缺口，不用猜测内容补全。
